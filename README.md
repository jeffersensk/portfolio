# Java Portfolio Website


This is a basic portfolio website for me to display my work in computer science and in music as well. Its also will be a place where I could share many things that I wanted to showcase. It is made using react because I want to practice + experiment with different cool react libraries

## How to run the site locally

1. Build the dependencies using `npm install`
2. Then if there are no vulnerbilities start up the website using `npm run dev`
